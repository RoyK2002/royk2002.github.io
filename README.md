# Roy Kurien — Personal Portfolio

A polished, responsive personal portfolio for Roy Kurien. The site is fully static and dependency-free, with an original editorial interface inspired by premium product design.

## Features

- Responsive, semantic HTML5 structure
- Light and dark themes with saved preference
- System theme detection
- Glass navigation and mobile menu
- Scroll reveal animations
- Subtle pointer glow and 3D tilt interactions
- Reduced-motion support
- Keyboard-friendly navigation and visible focus states
- No frameworks, build tools, external fonts, or runtime dependencies

## Run locally

No installation or build step is required.

### Option 1: Open directly

Open `index.html` in any modern browser.

### Option 2: Use a local static server

From this directory, use any static server already available on your system. For example, with Python:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` — semantic content and site structure
- `styles.css` — design system, layouts, themes, and responsive styling
- `script.js` — theme, navigation, reveal, cursor, and tilt behavior
- `README.md` — project notes and run instructions

## Browser support

Designed for current versions of Chrome, Edge, Firefox, and Safari. Core content remains accessible if JavaScript is unavailable; interactive enhancements require JavaScript.
